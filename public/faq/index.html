CRICS Offline Cricket Scoring FAQ

Does CRICS require internet for scoring?

No. Match scoring and local records are designed to work offline after CRICS is installed or loaded.

How do I install CRICS on Android?

Open CRICS in Android Chrome, open the browser menu and choose Add to Home screen or Install app when available.

Can I export or restore my CRICS data?

Yes. Use Backup and Settings to export all local records as a JSON backup and import a validated backup later.

Can CRICS export scorecards?

Yes. Match scorecards can be exported as PDF or image files.
