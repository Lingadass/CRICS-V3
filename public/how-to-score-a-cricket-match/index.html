How to Score a Cricket Match in CRICS

  1. Start a new match. Open CRICS and choose New Match. Select the teams or create them before continuing.
  2. Set the match details. Choose the batting and bowling teams, toss result, playing XI and match rules shown in the wizard.
  3. Open the live scorer. Confirm the opening striker, non-striker and bowler. The score keypad is ready for the first ball.
  4. Record each delivery. Tap DOT, runs 1-6, extras or WICKET. For a wicket, choose the dismissal type and complete the displayed fields.
  5. Change bowlers and innings. At the end of an over, follow the prompt to select the next eligible bowler. Start the second innings when the first innings is complete.
  6. Edit or undo when needed. Use Undo for the latest ball or Edit Ball to correct a recorded delivery.
  7. Finish and export. Finalize the match result, open its scorecard and export a PDF or image if needed.
