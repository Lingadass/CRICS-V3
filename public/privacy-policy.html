CRICS Privacy Policy

Effective date: November 13, 2026

CRICS is an offline cricket scoring web app and Android web app for cricket scoring, player registration, team management, career statistics and tournaments.

Zero data collection or transmission

CRICS does not collect, transmit, rent, sell or share personal data, device identifiers, location data, photos, contacts or usage analytics. The app has no user accounts or backend servers.

On-device storage

Players, photos, teams, match events, tournaments and scorer lock PIN hashes are stored in IndexedDB on the user's device. Browser or app storage controls can be used to delete them.

User control and backups

You can export a portable JSON backup from Backup and Settings, import it later, and delete individual records or application storage. You control whether sample data is present.
